## CPU同口径资源实测

独立`rv32_cpu_subsys`顶层，PG2L100H-6IFBG676，仅compile/synthesize/dev_map。相同8 KiB ROM、8 KiB RAM、3108字节固件、MMIO/UI发布接口；M/C/预测器关闭，无CPU共享DDR桥。paceRV额外取指端口在C关闭配置下按接口契约固定/停用，代码在隔离build副本内，不改生产CPU。

## 建议第一版范围（待功能讨论，不是已实现清单）

推荐“实时页 + 记录页”两页，当前最近8次的比例图保留。记录保存在已有CPU本地RAM，先按64条×16字节=1024字节预算，单页显示8条，超过容量覆盖最旧。此为会话记录，断电/复位清空；不保存或回放原音频，也不自动写Flash。

### Flow：实时观察

- 目的：看当前识别、8类置信度、输入波形及最近8次比例分布。
- 入口：启动默认进入实时页；从记录页返回。
- 状态：无结果显示空态；正常结果按双相动画更新；选择记录不停止I2S采集或NPU推理。
- 反馈：保持8类固定色，主结果卡、波形卡、比例历史卡分层。参考暖白/深绿与导航组织，去掉大幅口号和实现细节。

### Flow：记录回看与标记

- 目的：按序号/时间回看一条结果，查看该条完整8类概率并添加书签。
- 入口：从实时页切入记录页。
- 选择后：固定当前所选记录详情，后台推理及环形记录继续运行；若该记录即将被覆盖，保留一份选中快照，明确处理失效状态。
- 空态：无记录时不显示伪数据；清空后选中项和书签同时复位。
- 类别筛选和UART CSV导出可作为第二批功能，避免第一版同时增加过多状态。

### Component：记录与显示快照

- 原始记录字段：推理序号、开机后到达时间、8类原始百分比、raw top1、书签标记。
- 数据源：完整结果序号/概率MMIO。不能取动画中的UI_TOP1或淡出中的百分比作为原始记录。
- 显示只接收CPU整理好的当前页/8条记录摘要和选中详情，以请求/应答快照在帧边界提交。
- 数值格式化、筛选、索引、按键手势由CPU完成；像素域只做简单绘图与ROM读取，不加动态除法或长选择链。

### 按键方案待定

可借鉴KEY1短按选择、双击标记、长按切页；KEY2保留清空历史；KEY0只做复位。手势状态由CPU管理。当前`sys_ctrl`的KEY1在RUN中重触发DDR自检，接UI前必须移除该RUN态功能，保留故障恢复所需入口，不能让一次切页中断音频。

### 视觉约束与工程验收

- 目标：暖白背景、深绿导航、有限类别强调色、清晰选中边框；文字/颜色同时标识选中和收藏，不能仅靠色差。
- 复用现有字体/矩形/概率条和波形存储，检查新增字形是否仍在ROM容量内；不直接复制参考renderer/state模块。
- 保持125 MHz核心、148.5 MHz像素、48 kHz采集，不改DDR IP或通过放松约束掩盖违例。
- UI不增加DDR主口或整帧DDR帧缓冲，不逐像素请求DDR，不扩双模型/RTOS范围。少量控制和显示状态仍会有资源开销，不能保证“零复杂度”。
- CPU替换、UI美化、记录交互分阶段对照；分别跑CPU/数值/像素/按键验证，再做整机PDS和板级WOK、2kHz、90秒连续回归。
- 当前有效基线仍是815A6594；所有候选必须保留其已确认音频顺序及量化契约。


## 最终实现范围（用户已授权）

- 暖白底 `#f5f2e9`、深绿侧栏 `#173e32`，实时/记录两页；只保留必要标题、数值和简短按键标签。没有平滑说明、口号或硬件调试参数。
- 实时：声音波形、最近八次原始归一化比例柱、当前类别和八路置信度。旧值500ms退出、零点切类、新值500ms进入；首次只淡入。
- 记录：现有CPU RAM内64条环形记录（每条20B），包含完整8路原始百分比、top1、推理序号、会话相对时间和收藏位。记录页8条一组，查看选中条目的完整概率；浏览中保持同一条目，新推理不抢焦点。64条滚满覆盖最旧记录及其收藏；不保存音频、不跨复位持久化。
- KEY0维持复位；KEY1短按换页、长按600ms收藏/取消（实时页作用于最新记录）；KEY2短/长按均清空会话记录与比例历史；KEY3向旧、KEY4向新，长按各跳8条。20ms消抖，长按释放不再产生短按。
- KEY3=A22、KEY4=B20，均来自板卡权威引脚表；KEY1=C23、KEY2=B22。sys_ctrl的KEY1固定为不按，防止UI操作重启DDR自检；开机自检和错误处置保留。
- CPU MMIO +50读4个短按/4个长按计数（各4bit），+54读视图busy；+58元数据、+5c/+60选中概率、+100..+13c八行预格式化记录，+68提交。
- 608bit视图采用持有bundle和req/ack跨时钟握手，只在帧边界生效，busy期间拒写；没有新DDR主口、像素域记录扫描或整帧缓冲。序号/时间/行百分比在CPU转BCD。
- 固件4564B，BSS1428B，原8KiB ROM/RAM均有余量。新增RTL测试覆盖CDC提交/busy保护/消抖/短长按；C测试覆盖环回覆盖、原始概率、稳定选中、收藏和清空；实际CPU测试覆盖两阶段动画及记录MMIO联动。板测与资源/时序以新构建报告为准。
