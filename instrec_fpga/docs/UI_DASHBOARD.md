# 1080p 显示改版

## Flow: 看懂音频与最近识别结果

### Overview

观看者无需了解 FPGA，也应能区分输入声音、频谱特征和模型输出。固定目标是 1920×1080 HDMI；本轮只做 RTL 仿真，不烧录、不启动 PDS。原八类单标签模型及类别顺序不变。

### Steps / states

1. 启动时显示中文区块说明、空图网格、“等待音频窗口 / 等待频谱数据 / 等待识别”；未得到完整结果时百分比显示 `--%`。
2. 完整波形窗口与频谱页各自就绪后，填充对应图区。频谱高 Mel 频带在上、低频带在下，时间从左到右；颜色表示能量，不表示类别。
3. 收到完整八类概率快照后，仅在帧边界更新最近结果、类别名称与百分比。下一轮计算时保留最近完整结果。
4. 仿真样例显示“仿真演示”标识，避免把样例输入当作真实采集或准确率证据。实机模式不显示此标识。

## Component: 输入波形

### Purpose

解释原来顶部大图的含义：声音振幅包络随时间变化。将其限制在左上卡片内，避免铺满顶部或与频谱重叠。

### Props / layout

- 卡片 `(64,160)..(1184,512)`；图区 `(128,288)`，1024×160。
- 读取整个 1920 列音频窗口，缩放成 1024 显示列；中心为零振幅，显示正/负振幅参考和时间方向。
- 中文标题“01 输入波形”，说明“声音振幅随时间变化”；未就绪显示空态。

## Component: Mel 频谱

### Purpose

独立展示本次分析窗口的频带能量，提供坐标与色阶说明。

### Props / layout

- 卡片 `(64,544)..(1184,1008)`；图区 `(128,672)`，1024×256。
- 使用全部 64×258 特征；纵向高频到低频，横向早到近；标注 Mel 频带和能量色阶。
- 未提交完整特征页前显示“等待频谱数据”，不显示 RAM 初始内容。

## Component: 识别与类别置信度

### Purpose

让观看者明确知道识别到了什么，以及每条横条属于哪个类别。

### Props / layout

- 右卡片 `(1216,160)..(1856,1008)`；大字显示最近完整类别及其置信度。
- 八行固定顺序：单簧管、失真电吉他、女声、长笛、钢琴、次中音萨克斯、小号、小提琴。
- 类别名从 y=448 起每 64 像素一行，下一行内显示 400 像素全量程横条；每行右侧显示数字百分比。
- 高亮获胜类别；其他类别使用较淡颜色，文字和数字同时表达含义，不依赖颜色辨认。
- 页脚说明“百分比表示模型置信度”；它不是五组活跃度，也不是实测识别准确率。

## Tokens / accessibility / motion

- 背景 `#0B1020`，卡片 `#121C2D`，描边 `#27364C`。
- 主文字 `#EAF0F7`，次文字 `#9AABC0`，主强调 `#36D6C5`，仿真标识 `#F2BA59`。
- 正文 32 像素字格，结果 64 像素字格；使用完整分辨率中文位图字形。
- 固定电视画布，无鼠标、键盘、hover、DOM/ARIA 或响应式网页需求。四周至少 64 像素安全区。
- 无装饰性动画；完整快照在垂直消隐期间提交，绘图与同步信号固定四拍对齐。

## Engineering handoff / acceptance

设计规范阶段完成后，由本任务继续实现 RTL。保留独立显示演示工作树，改版不覆盖此前已确认可显示的位流。

- 从实际 RTL 全帧仿真导出等待态与有结果态 PNG，逐张视觉检查；软件示意图不代替 RTL 结果。
- 验证帧像素数、同步信号延迟、图区边界、RAM 地址范围、百分比 0/100 与未就绪语义。
- 保留中文字体/字图/图块生成脚本及 ROM 数据，并纳入重建资产。
- 本轮不宣称 PDS 资源/时序收敛或板级显示通过；新增 ROM 预算约 6 DRM36K，实际映射留待后续构建核验。
