# 指令 Cache 同步读块 RAM 候选

本页记录D681及之前的历史阶段。后续扇出32与保留ALU高段预计算版已通过132/135 MHz本地性能、验证两组实现，见ALU_KEPT_PRECOMPUTE.md；本页失败结论不再描述当前生产源码。

日期：2026-09-07。此阶段继续优化执行效率、频率和资源效率，不更新正式实板成绩，也不上传 GitHub。

## 源码与比较边界

前一版本 Cache 的 SHA-256 为 D66A1DAF2969E316084221C0FFE86772AD1B8ADD0540C0989ED215121F3CCE8B，完整保存在 experiments/cache_readonly_writeback/rv32_cache.sv。其同条件132 MHz性能实现为20260907-074248-6dd640cf：9236 LUT、5064 FF、16 DRM、4 APM、WNS +0.082 ns，仍是本地实现而非新的板测成绩。

当前生产候选 Cache 为 D6817DA883432CD3409165805DADCEF9DA7A26D56C1BD213CC4F47EC0A628F0D，其他硬件输入及8 KiB I-cache/2 KiB D-cache参数保持。READ_ONLY=1时，每一路数据使用独立同步读存储；读地址在ready窗口选择外部请求，在忙时选择已保存请求。请求被接收的同一个时钟沿启动RAM读取，下一LOOKUP周期即可使用数据，不人为增加命中气泡。

回填写入与读地址相同时显式保存该拍数据和逐路旁路标志；特别覆盖请求最后一个字、最后一拍回填后立即进入LOOKUP的情况。RAM数据和读输出不复位，写入和旁路标志遵守异步复位；标签及有效位仍由原状态机管理。READ_ONLY=0保持异步数据读出、字节合并、脏行写回与原事务时序，只把存储更新组织到独立generate分支。

属性依据本机PDS 2022.2-SP6.4的ADS_Synthesis_User_Guide.pdf第5.16节（印刷93–95页；本地提取build/ads-synthesis-guide.txt）。使用syn_ramstyle=block_ram，不使用可能导致RTL与综合网表行为不一致的no_rw_check。推断结果仍须由原生网表和最终资源报告确认，不能只凭属性宣称节省。

## 验证方法

新增scripts/test_cache_synchronous_read.py把当前RTL与固定D66基线逐周期比较ready/valid/error、有效响应、有效命令、写回数据、计数器及state/valid/dirty/LRU。32种基础组合加16种实际容量组合（地址16/32位、SET_BITS=6/8、快读和重叠开关）通过；16种实际容量也独立运行原基线，防止新驱动只适配候选。容量用例覆盖两路末拍旁路、三组冲突标签、256笔随机地址、背压、刷新、读错误、早/晚last、非法写和未对齐地址。

7个编译成功后运行失败的错误注入检查旧地址读、忙时错误使用实时地址、分别删除两路旁路、错误选路、错误写路和只在req_valid时读RAM。没有放宽lint或把编译失败当作功能反例。

扩展容量测试首次发现旧overlap_stream在一段无效请求噪声后启动读事务时漏设req_write=0；固定D66源码也在同一周期8444复现错误。驱动现已显式设置方向，未删除噪声或背压断言。历史scripts/test_cache_ready_payload.py改为检查保存的D66夹具，仍以原SHA严格逆变换到AC24并核验C3夹具，保留原13个运行控制；当前生产源码由新的D66对照测试覆盖。

## 短测与初版失败

C7过渡版的性能10轮构建20260907-085048-59fc0231：3307565周期、2748941退休；验证10轮20260907-085055-101a962d：3308242周期、2749614退休。分别与D66相同固件短测的UART逐字节相同，配置、完整解析结果、18份输入、固件和编译可执行文件均核验；见build/cache-synchronous-read-short-audit.json。短测约0.025秒，只证明这一工作负载没有执行拍数退化，不能作为正式CoreMark分数或新实板资源效率。

初版DA53B966候选虽然定向等价测试通过，但编译式构建20260907-084738-95b63dc6被严格lint拒绝（只读分支未使用信号及复位混用）。对应初版完整回归被明确取消，不记为通过；初版PDS构建20260907-084703-d2658f6f只作为探索记录，不能作为C7候选证据。修正RTL后重新开展定向、完整回归、外部ISA与PDS；不扩大告警白名单。

## 单写端口修复

C7C4611B过渡版完成全回归及196次外部ISA，均通过；但132/135 MHz原生网表显示D-cache数据被展开为16384个GTP_DFF_E，原536个GTP_RAM64X1DP只剩标签所用的24个。原因是拆出的更新块保留两个独立数组写入口，ADS未把它们合并为可映射RAM的单端口。因此不能仅凭仿真通过或I-cache映射成功宣布资源优化。见build/cache-synchronous-read-c7-inference-audit.json。三个初版/过渡版PDS任务在确认这一资源退化后主动取消，保留源码与网表，不称为最终时序失败或合格位流。

D6817DA8将写命中与回填写入先合并为store_index/store_data及写使能，数组只有一处写赋值；字节写语义、错误保护和异步复位写保护保持。132 MHz构建20260907-090310-26973eda的原生网表已确认D-cache恢复536个GTP_RAM64X1DP，不再有16384个数据触发器；I-cache从1056个降为32个GTP_RAM64X1DP（标签）并增加2个GTP_DRM36K_E1（每路1024×32数据）。这是实际推断结构，尚不等同于布局后的LUT分母。见build/cache-synchronous-read-single-port-native-audit.json。

当前单写口版两种种子短测20260907-090259-df7cf4b2、20260907-090306-b17abbb9再次保持3307565/3308242周期及2748941/2749614退休，UART分别与D66逐字节一致，18份输入、执行文件、固件及结果重新核验；见build/cache-synchronous-read-single-port-short-audit.json。新的48种定向配置及7个运行反例通过；C7的全回归、ISA结果仍仅作为历史记录，当前源码重新验证。
