# 同周期延后WB分支比较结果选择

## 当前目标与真实路径

当前目标仍是实际合格频率≥160 MHz、执行效率≥3.18 CoreMark/MHz、资源效率≥0.052 CoreMark/LUT；达到新版目标后，后续升频不得降低任一效率。

直接前驱timer-compare-split-162000-stage的实际PDS20260908-160335-5ceb109f已失败：162 MHz、8975 LUT、5184 FF、WNS -0.736 ns。独立原始报告与来源审计通过，8项方法168.000秒及14项实际物理/网表拒绝控制通过，时序和完整双种子门禁正确拒绝。这不是162 MHz合格结果，也没有进行完整计分。

实际最差路径从WB目的寄存器号wb_rd[2]经过前递选择、early_operand_b[5]、低字节比较、分支/取指控制，到I-cache状态寄存器CE，共9级逻辑，数据路径逻辑1.833 ns、布线4.571 ns。原生网表N652.slt_3的输出确为early_byte_less[0]，不是凭名称猜测为整条32位比较链。需要缩短的是晚到的WB选择信号穿过比较运算的路径。

## 电路修改

规范源experiments/late_wb_branch_select/rv32_core.sv，SHA256为6741A6D0569E47CF1FE8B2BA9862692011CFE13941AE9F971B252C95A34B7364；隔离工程build/late-wb-branch-stage。20份物理输入中只更改CPU比较块，其他19份及实际162 MHz固件不变；原CPU为734B1D48A89D4A60A32A24154593BBA0AC6D33F226959AA1BD50CCD158C93CFF。

在同一周期内并行计算三组比较：非WB来源A对非WB来源B、WB数据对非WB来源B、非WB来源A对WB数据。最后根据两侧是否真正选择WB进行一位结果选择：两侧都选WB时相等恒为真、小于恒为假。MEM前递优先于WB，零寄存器及不使用的源操作数仍取零；有符号结果保留原符号位规则。各组仍使用四个8位比较及高位优先组合，并保留比较边界供实际网表检查。

没有新增寄存器、流水级或等待气泡，没有改变EX/MEM冲刷、异常、预测或加载地址前递。收益只是待验证的结构假设：减少WB寄存器号选择信号进入多位比较链的延迟，代价是增加并行比较逻辑；是否改善时序和资源效率必须看新PDS及完整成绩。

## 已完成的功能证据

- 比较块以真实原/新RTL提取建立探针，原/新各589824组独立参考检查，包括524288组选择/优先级组合与65536组随机数据；3项方法15.284秒通过。八个错误变体均实际被拒绝，覆盖MEM优先级、双WB相等/大小、两侧选择颠倒、未使用源寄存器与符号规则；错误变体之前先运行正确候选。
- 原重定向矩阵四种气泡/重叠组合、12项重定向错误变体通过；3项方法3.780秒。返回错误矩阵24项检查及4项错误变体通过；2项方法1.327秒。日志中的FATAL属于预期反例拒绝，不是正确实现失败。
- 八组严格板级lint及两组缓存CPU独立参考通过，均核对13次陷阱和16384字节最终内存。
- 新性能短测20260908-163007-8ae26d06：3151519周期、2748941条退休、最终CRC fcaf。新验证短测20260908-163025-3ffddef4：3156276周期、2749614条退休、最终CRC c64e。均与前驱相同，但短测不产生完整成绩。
- 当前I9/D6配置下98组ISA配对共196次实际执行及8项拒绝控制通过。源文件只允许新比较核心的单一差异，逐组强制周期和退休数相等，并核对退休轨迹、最终内存及原始固定固件的实际工作量，没有放宽比较。
- 四组SoC配对共8次执行通过，完整输出与退休轨迹严格相等：GPIO/UART正常路径8228/8231周期，退休4611/4732，三种中断各一次；错误路径4407/4715周期。

初始严格lint发现保留的原操作数低31位和函数相等参数最低位不再参与硬件输出。没有关闭任何告警：采用现有unused命名惯例标记仅用于观察的低位，并把函数参数收窄到实际使用的[3:1]，随后全部单元及集成检查重跑通过。首版功能通过日志与首次lint失败日志保留。

首次新输入审计查找了候选目录中不存在的PLL模型日志，PDS因此未启动。已经改为明确引用同源码、同162 MHz固件前驱的八频率原厂模型证据，并继续逐项验证PLL源文件和台架一致；失败日志保留，没有伪造或重标低频结果。当前输入审计已通过。
