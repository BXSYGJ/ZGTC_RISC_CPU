# WB相关比较的字节预计算

## 设计

直接父版为 predictor-index-maxfan-stage（PDS 20260909-033846-fb07f70e，157.5 MHz WNS -0.317 ns）。实际最差路径经过EX-A与WB的比较、分支决策和操作数使能。因此本候选把第2组WB/EX-B、第4组EX-A/WB的四字节相等及小于结果提前保存到16个状态位。字节间优先组合、有符号选择、分支来源优先级和决定时刻不变。

下一操作数使用原来相同的顺序：默认保持、EX有效时刷新、ID传递覆盖；WB仅在mem_fire且无故障时接收mem_value。四态控制使用与原时序块一致的过程if，不以三目表达式合并未知控制。复位时相等标志为1、小于为0，不增加流水级或加载/分支气泡。

源 `experiments/wb_byte_retime/rv32_core.sv`，SHA256 732509AD595EBC6EA0FD0B35F3D6ABA754D1D2169B27C3B5AF435BBFECCE0AC3；另19份物理输入与父版一致，保留BBB预测器、共享移位ALU和157.5 MHz PLL。
