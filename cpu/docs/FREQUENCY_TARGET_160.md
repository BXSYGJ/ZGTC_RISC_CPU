# 当前160 MHz目标与162 MHz候选

## 当前目标

2026年9月8日用户将初始频率门槛由150 MHz提高到160 MHz。当前必须同时达到：实际时序合格频率≥160 MHz、执行效率≥3.18 CoreMark/MHz、资源效率≥0.052 CoreMark/LUT。达到这一新版目标后，后续每次升频均不得降低相对上一合格版本的两项效率。

已经冻结的151.2 MHz版本仍是有效的历史RTL/PDS基线：3.181369715697977 CoreMark/MHz、0.05357201258642768 CoreMark/LUT；但其频率不足，不能声称新版目标已经完成。保留原始证据及哈希，不把旧报告中的150 MHz门槛篡改为160 MHz。当前精确门禁位于scripts/frequency_target160.py，初始条件与达标后的单调升频阶段明确分开。
