## 电路改动与边界

实际失败的145.125 MHz前一版本从D-cache同步读输出经过加载前递、地址/控制进入下一请求；候选仅改变同一CPU的D-cache响应数据选择。原表达式先在每一路选择读存储输出或碰撞前递数据，再按hit1选路。新表达式先译码三个互斥条件：way0且不前递、way1且不前递、所选路前递，再按位掩码合并三个32位数据源。

没有增加寄存器或流水拍，没有更改请求ready/valid、响应valid、写命中字节合并、读写碰撞标志、回填、脏行写回和回压、刷新、标签或LRU策略。w_data仍使用原两路选择，I-cache分支原文不变。新语法表达并不保证映射后所有路径只有一级LUT；实际原生网表会与下游加载格式等逻辑合并，以PDS为准。
