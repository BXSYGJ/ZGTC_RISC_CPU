# D-cache 有效位分组采样候选

## 范围与硬件假设

本候选位于experiments/dcache_valid_banks/rv32_cache.sv，隔离工程为build/dcache-valid-banks-stage。固定字节进位核心FCD29C622EFA23A666398EC27324A97A2291D1079A24CC6949FE91A74E1DFF99、146.25 MHz PLL及原始memory_system；20份物理输入仅cache文件改变，候选SHA256为A3B10973E0D24038B46FC8D387F400E6256B54CDD3027F21035B1EBCABFA9B9B。不叠加刚失败的RAM地址域化，不替换生产RTL。

RAM域候选真实最差路径经过D-cache返回数据、地址低字节进位、地址bit9和64选1有效位读取。本候选仅在可写缓存且SET_BITS>4时，把每路有效位分成16组一块：时钟沿前只用低四位在每块16选1，同时寄存高位块号；时钟沿后按已寄存块号选择有效位。目标D6每路四块，新增的理论状态是6个有效位寄存器加2位块号，不增加请求/响应流水周期；实际资源和时序以PDS为准。

req_ready时更新所有块和块号，保持原来无需req_valid即可预采样的语义。未就绪时保持状态；成功填充按victim路把该路各块的采样位置为1，当前块号保持不变，因此对外有效位仍与原实现相同。错误填充不提交，复位全部清零。块号再次变化只可能同时重采样所有块，不会暴露其他块的临时填充值。只读和小集合缓存保留原分支。此说明是结构推理，实际等价验证边界如下。

## 保留的测试准备失败

第一次运行69.893秒失败：复用旧观察器引用不存在的lru字段，以及I9白盒刺激逐位更新整幅强制信号带来的60秒超时。新建局部观察器按实际lru_storage逐项检查，未修改旧夹具；先构造完整图样再一次赋值，保持同样采样刺激并把外部超时调至180秒。

第二次90.504秒失败：把假设两集合冲突地址的基础流用于D6，使原缓存即触发LRU断言；I9全容量流虽通过容量断言，但不提供该观察器要求的末拍转发覆盖。改用已有几何感知事务流，断言和同步转发覆盖不放宽。两份失败日志dcache-valid-banks-unit.log及dcache-valid-banks-unit-qualified.log保留；名字中的qualified不代表通过，以实际结尾和最终审计绑定为准。RTL在这些夹具修正期间未改变。

第一次筛选审计生成时JavaScript替换字符串错误解释正则尾部的美元符号，导致Python语法错误，在PDS启动前拒绝。改为字面回调替换后，审计正常通过；原失败screen-audit日志保留，没有修改原始结果。

## 物理和总体验收边界

实际PDS构建20260908-102107-1fb3a46a已结束，PG2L200H-6FBB676、146.25 MHz、种子1、RemoteLab 115200，固定同频6000轮性能固件。实际原生网表确认四块有效位和2位块号，20份源、完整Tcl/布局种子、固件、顶层和原始报告审计通过，但强制时序门明确拒绝：8771 LUT、5132 FF、WNS -0.036 ns、1个setup失败端点。未生成通过manifest，未执行完整计分，不产生本候选完整分数。物理审计另以2项方法22.383秒验证3类拒绝：缺失原生分组状态、错误PLL反馈比、解析结果与元数据一致但错误的时钟周期；原始报告不修改。

相同种子父方案8694 LUT、5125 FF、-0.036 ns；本次增加77 LUT和7 FF，没有改善最差裕量。最差路径已不是有效位读取，而是D-cache存储bit1经返回数据选择、低字节进位、d_req_address bit21及地址合法性判定，进入rsp_error寄存器；逻辑3.342 ns、布线3.074 ns。只能说明这次实现的最差端点发生变化，不能据此证明所有有效位路径都满足时序或已经找到全局最优。后续需针对返回数据到地址合法性控制的完整路径另做独立实验。
