## 候选实现

保留表项数、目标地址、标签、2位饱和计数器和错误地址过滤，只将索引改为PC低索引位与相邻高索引位异或；fetch/update使用相同公式。高位标签相同且折叠索引相同才可命中，因此不能删掉标签比较。HASH_INDEX=0保留原索引作消融，候选模块默认1。配置字未新增位，必须用实际源码快照区分候选与旧版本，不从相同配置字推断同实现。

## 事件复测

对相同1轮固件机器码与相同有大小的符号表，计数窗口从335377降到333370拍，退休274843条不变。条件分支重定向6822→6489，JAL 138→145，JALR 170→166，乘除法等待9495及访存等待1177不变，取指等待8044→8076，前端空27283→26277。没有声称每一种事件都改善，也不将重叠类别直接相加。ELF文件本身哈希不同，记录只声明HEX和符号表相同，不冒称ELF逐字节一致。证据build/profile-btb-folded-rotate4-comparison.json。

## 测试覆盖与边界用例修订

test_btb_folded_index.py对索引宽度1/4/6/7/8、地址宽度16/32、折叠开关0/1、旋转0–7做160配置测试；只修改取指/更新一侧折叠及移除标签比较三类故障各8旋转，共24反例必须运行失败，均通过。检查冷缺失、计数器饱和、替换、无条件跳转、失效/复位、未对齐过滤及所有表项保留。

原btb_bounds_tb假设PC=0与最高地址永不冲突，但在若干折叠配置中它们实际映射同一项。未删除边界/错误更新断言：改为分别训练并检查两端，完整容量检查继续使用互不冲突的低地址；标签替换用按模式推导的真实冲突地址。修订前失败日志保留为test_btb_address_bounds.log，修订后test_btb_address_bounds-fixed.log的六组正例及四类指定原因拒绝控制均通过。新折叠测试已接入validate.ps1。
