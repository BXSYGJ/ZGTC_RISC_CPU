## 2. 100H vs 200H 的关键差异

- 同为 Logos2 -6 速度档，但这颗 100H（封装后缀 I，疑似工业级）时序比定稿 200H-6FBB676 慢约 17%
  （153 MHz 估计周期 7.641 ns vs 200H 定稿收敛于 6.535+0.021 ns）。
- 瓶颈在**布线**（路径延迟 77% 为布线）；布局种子扫描方差约 ±0.2 ns，救不回 1.1 ns 缺口。
- 板载时钟同为 27 MHz（D18），UART 板载 CP2102（RX B24 / TX C24），LED 引脚表与 200H 相同。
- DDR3 IP 同一份加密 RTL，仅 .idf 目标器件/引脚表不同（73 针表见 `pds_cpu_100h/constraints/ddr3_100h.fdc`）。

## 3. 构建与使用

```powershell
# 27 MHz 主线配置（带 DDR3）
pwsh -NoProfile -File pds_cpu_100h/scripts/run_pds_full.ps1

# 定稿高性能配置，任意 PLL 频点（默认 153000000，100H 上用 120000000）
pwsh -NoProfile -File pds_cpu_100h/scripts/run_pds_153.ps1 -ClockHz 120000000

# CoreMark 固件（ClockHz 需与硬件一致）
pwsh -NoProfile -File pds_cpu_100h/scripts/build_coremark_100h.ps1 -ClockHz 120000000 -Iterations 1000

# 烧录（JTAG RAM 加载，断电即失！）+ 串口加载
#   program_full.tcl（cdt_cfg，须 jtagserver 65420 在跑）
#   python tool/serial/serial_cli.py load <app.bin>  → 发 G 启动
```

详细调试记录与坑位：`docs/skills/pango-pg2l100h-dev/references/cpu_serial_flash.md`（§8 DDR3、
§9 频率收敛、JTAG RAM 掉电即失说明）。
