# 单槽循环预测器：保留执行收益，独立检查时序与资源

## 动机与实现

前驱两槽同拍训练旁路版双短测各节省9900周期，但157.5 MHz PDS WNS -0.258 ns，不可升级。原冻结本地501.065730222分版本保持。

build/loop-predictor-bank-mask-proxy.json使用已绑定的648458条实际分支解析轨迹，保留原H3基础预测器对全部分支的训练，仅屏蔽独立循环表的查询覆盖。mask=1与mask=3在条件分支窗口均减少1980次方向错误、没有新增错误；mask=2没有改善。未屏蔽结果逐项还原既有42组索引筛选中的对应候选。这仍是解析顺序代理，不是硬件周期、面积或正式成绩。

唯一RTL experiments/loop_predictor_single_bank/rv32_btb.sv，SHA256 13CE1849DE67455BBD212A6F35B21367F34127974A54EF1B2EA488D373989984。仅保留一个真实存储项，循环表索引固定零，折叠BTB索引的第5位为零时允许训练循环项；基础BTB仍对所有合法分支训练，完整PC标签保护不相关分支。索引不足6位的配置允许全部地址，避免非法位选。

保留前驱的同拍taken训练旁路、预计算超前方向、5位计数、置信和溢出处理。RTL不按CoreMark地址或固定循环长度编写例外。单槽相对两槽的变更可通过 scripts/loop_single_bank_changes.py 精确还原；CPU、PLL、固件及另外19份物理输入不改。

## 已验证

- 独立模型保留基础BTB训练，同时拒绝另一槽对循环状态的更新；加入交错分支刺激，防止错误准入反复覆盖已学项。
- 5种索引/地址/散列配置，共58236条输入、116472次正沿前后查询，379次可观察的旁路方向改变；3项4.994秒通过。
- 12个实际运行错误变体全部拒绝，包括准入缺失/反转以及旁路资格、超前次数与回绕。单槽索引已是常数，不将前驱的槽位比较冗余变体冒记为仍可检测。
- 8种严格板级lint、缓存CPU独立参考和三个PowerShell入口解析/UTF8 BOM检查通过。

## 最终物理结果：失败，不采用

PDS构建20260909-064324-d3f30e30已结束：157.5 MHz、布局种子2，9538 LUT、5292 FF、WNS -0.332 ns，无合格manifest。原始来源和报告已由 build/audit_loop_predictor_physical.py --candidate single-bank 复核。

相对于两槽版，虽然FF少9个，但LUT多63个，WNS再差0.074 ns；不能按RTL存储项数量预先认定资源改善。最差路径为id_instruction[21]经寄存器读选择和比较，到raw_pair_relation[0]；id_rs2[1]一段实际扇出74、布线1.575 ns，全路径逻辑1.648 ns、布线4.457 ns。

独立ISA 98对/196次、8个实际错误输入拒绝和SoC 4对/8次均通过。原始证据检查4项579.569秒、18个篡改/展开标记反例全部通过；这些功能证据不抵消物理失败。

本候选关闭，不运行完整计分、验证固件PDS或上板。回到物理面积和时序相对更好的两槽旁路版，针对已确认的WB目的编号非零归约路径，建立 loop-pending-wb-nonzero-stage；见 LOOP_PENDING_WB_NONZERO.md。冻结基线不替换，不提交/推送GitHub；完整非AI验收继续开放。
