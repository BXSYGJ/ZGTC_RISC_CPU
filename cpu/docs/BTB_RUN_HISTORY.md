## 范围与证据来源

当前冻结基线为157.5 MHz、501.065730222 CoreMark本地资格版本。以下全部候选不修改固件、指令流、编译选项、CPU或缓存；先对同一648458条真实分支轨迹做解析顺序代理筛选，再决定实际RTL。原始轨迹SHA256 5B716144F4496B1101026DDC0D4E671C4B9D81056C5C58C236800A237EE5533F；每次运行重新完整解析并与已资格报告比较。

基线窗口包含524172次条件分支和53871次重定向；三个独立筛选中的基线均逐条匹配窗口内观测。代理没有取指停顿、错误路径与在途更新的精确时序，不能将减少的重定向直接换算成周期或正式CoreMark。每个新结果使用独立文件且禁止覆盖。

## 双向连续长度RTL

规范源码experiments/btb_run_history/rv32_btb.sv，SHA256 0FF6374376C12FBD4467BA20523A2ED60E0BF1E56A97953E9CC1F4BF8E2D5DC9。以冻结BBB08D9A预测器为父版，不叠加任何循环表。最高历史位保存最近方向，其余位表示该方向连续长度减一，饱和到3；方向变化时清零长度并更新方向。训练旧历史对应的计数器后再更新历史。初始化、失效、地址对齐/越界保护、标签、目标和计数器饱和策略均保留。HISTORY_BITS=1时退化为原一位方向历史。

实际Icarus测试3项5.842秒通过：72种参数配置、171432条向量，10个编译并运行的错误变体被拒绝，含方向反转、去掉饱和、冻结/误用移位历史、错误训练银行、失效和地址合法性。8种严格板级lint、缓存CPU独立参考、三个PowerShell入口解析与BOM通过。
