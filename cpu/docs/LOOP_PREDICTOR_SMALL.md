# 两项循环预测器：实际流水线未出现短测收益

## 来源与选择

基于已冻结的501.065730222分本地版本，只更换预测器；CPU、PLL、固件及另外19份物理输入保持。基线及121件冻结证据不变，没有Git操作。

索引/位宽代理额外筛选42组：2/4/8项、合法索引位片、5/8位计数器，置信门固定2。零偏移与首轮模型81920条输入及最终状态完全一致，3项0.346秒通过。四项/偏移1/5位可在代理中净减少2460次方向错误；两项/偏移5/5位减少1980次，故先选择状态量更小的后者进行真实RTL试验，而不是直接按代理数字宣称加速。

唯一RTL为 experiments/loop_predictor_small/rv32_btb.sv，SHA256 826199447568BB4D2BE0BF3D48CFF50E8393AE3EF722666EABA770BEDCC346E0。增加两项循环表，每项保存完整字地址标签、5位当前次数/已学长度、2位置信、溢出及下一查询方向。方向在训练沿提前计算，不在查询路径串入次数比较，不增加CPU流水级。复位和失效清除循环有效位；非法地址不训练；同PC改为非循环类型时使相关循环项失效。

初始索引截断写法改为显式generate连线，较小原BTB索引宽度时高位补零，避免宽度警告与不兼容的定宽转换；功能保持。最终源码能够精确还原BBB08D9A父预测器，未误改原历史计数器更新。

## 已通过的检查

- 独立训练/查询模型用当前次数与已学长度直接计算方向，不复用RTL的预计算寄存器；5种索引/地址/散列配置各10710条向量。
- 6个实际运行变体拒绝：无置信覆盖、反向预测、次数差一、错误接受前向分支、忽略溢出、冻结已学长度。
- 首次单个超长循环未暴露溢出反例，不能算通过；改为重复40次taken的循环，使错误回绕后的长度学习可观察，最终完整3项1.849秒通过，失败日志保留。
- 8种严格板级lint、缓存CPU与独立参考通过。三个PowerShell入口通过解析/BOM检查。

## 实际查询时序已定位

独立只读观察构建 20260909-060214-5c7d5327 仅更换仿真驱动，18份编译输入中RTL和判分脚本均不变，UART与短测结果逐字节保持。实际观察650398条事件、61200次查询及其下一正沿捕获，独立状态重放完成6678430项状态检查。

PC 0x514 的1980次已合格近出口查询均见count=28、trip=29，并仍预测taken；全轨迹统计确认这1980次全部同时存在同PC的有效taken训练。到出口分支解析时count才成为29，携带的预测仍是taken。不是接口猜测：update_target实际来自mem_target，查询值也逐次核验了下一正沿fetch_prediction/fetch_address的捕获。

因此解析顺序代理先应用训练再查询，比实际同一正沿之前的查询超前一次。对应的修正已在 experiments/loop_predictor_pending/rv32_btb.sv 隔离实现：根据同拍待提交训练选择预计算的一次超前方向；不改本页原候选。详见 LOOP_PREDICTOR_PENDING.md。

本页原候选仍是没有短测周期收益的版本，不因后续修正而补记成绩。原失败门禁和零收益构建保留。新候选的频率、精确资源效率均不得低于冻结基线，新实板与全部非AI任务验收仍未完成。
