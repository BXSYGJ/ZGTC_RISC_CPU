## 物理失败：不升级冻结基线

157.5 MHz、布局种子2、性能6000轮固件的PDS构建 20260909-062346-a8dbec11 已结束。实际布局后9475 LUT、5301 FF，setup WNS为-0.258 ns，时序不通过，没有合格manifest。

最差路径从WB目的寄存器wb_rd[4]经前递选择、ALU减法及结果选择到mem_result[24]；该条路径的逻辑/布线延迟为2.141/4.170 ns。不能把这个物理失败说成新旁路自身已形成关键路径，也不能把PDS估计频率当成实际主频。

build/audit_loop_predictor_physical.py重新解析原始报告并绑定20份实际物理输入、生成顶层、布局种子、原固件、综合网表和位流。4项51.460秒检查通过，8个元数据/产物反例拒绝；实际 --require-timing 入口也拒绝本构建。没有执行本候选的6000轮完整计分、验证固件PDS或上板。

ISA回归为98对、196次实际运行、8次实际失败输入拒绝；两种外设固件及正常/维护错误路径共4对8次SoC运行，原始完整轨迹和计数一致。独立证据校验4项544.076秒通过，18个元数据/原始日志/实际展开标记反例拒绝。
