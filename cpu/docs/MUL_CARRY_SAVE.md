# 乘法部分积进位保存压缩

2026-09-07。独立优化实验，针对分支专用加载前递候选的实际PDS关键路径，不增加乘法响应等待拍，不修改生产输入或GitHub。

## 从路径到电路

原候选135 MHz路径起点是multiply_divide.unit/N71/gopapm，终点为core/mem_result[30]。报告显示部分积寄存器输出后经过三个串联APM加法传播级（各1.431 ns），再经过结果选择。不能根据“乘法”名称就认定需要新乘法器或增加流水线等待。

现有四个16/17位乘积寄存器保留：LL、LH、HL、HH。LH/HL为34位有符号交叉项，HH保留低32位。64位乘积可写为：

P = LL + (LH + HL) × 2^16 + HH × 2^32，按2^64取模。

低16位直接为LL[15:0]。上面48位只需把三个48位数相加：

A = sign_extend_48(LH)
B = sign_extend_48(HL)
C = concat(HH, LL[31:16])
S = A xor B xor C
K = ((A and B) or (A and C) or (B and C)) << 1
P = concat((S + K) mod 2^48, LL[15:0])

这把串行“交叉项相加→加LL高半字→加HH”改为一次无跨位进位的压缩和一次末级进位传播。34→48位的14位符号扩展不可丢；移位产生的第49位应丢弃，对应整体乘积第65位，符合RV32乘法截取语义。

## 两个独立实现

- rv32_muldiv_csa.sv：普通48位末级加法，源SHA-256 0A318CBB26FC16ECCFA4C556C5550BD5E816EC186C9619F01EFC0CC80DC4769E。
- rv32_muldiv_csa_select16.sv：末级分成16/16/16位，后两段预计算进位0/1并选择，沿用现有ALU的syn_keep写法；源SHA-256 0901AFDB721FC22C91C5C1C667AD241550EC909DC9285BBEB2EA8107D1B0A73A。

两个版本均只替换乘积组合约简，不改输入捕获、状态机、早响应条件、取消、反压或除法。MUL/MULHU的请求后响应等待仍为0，MULH/MULHSU仍为1；不能把减少组合级数称为减少CPU执行拍数。

## 单元证据

scripts/test_mul_carry_save.py的8个方法通过：两个版本分别对263168组有效部分积做完整64位比较，同时对照原版约简与独立64位乘法，共526336组。包含16×16边界交叉和65536组固定随机操作数，每组四种乘法操作。

两个版本各通过原12544项算术、八种操作、精确延迟、反压和取消检查。10个算术变异以及每版2个响应时序/覆盖错误变异均被拒绝。原scripts/test_mul_request_capture.py仅增加可覆盖的candidate_path方法，默认生产路径保持不变；其原3个方法重新运行通过。

该miter只对真实32位乘法所能产生的部分积做硬件等价比较，不把任意不可能的34位交叉项组合当作原设计契约；另外的宽乘法参考独立验证最终数学结果。组合测试不替代CPU精确中断和SoC集成，相关构建审计与物理结果见下一节。

各结果为同135 MHz、种子1，均All Constraints Met、4 APM；既有十轮周期、退休指令、CRC与UART均需按各构建独立审计。末级进位选择增加面积且裕量低于普通版，不能仅凭RTL级的理论路径更短就宣称更好。PDS估计频率不是新频点的资格，更不是板测Fmax。

普通版最差路径转到ex_instruction寄存器经通用结果路径，前述串联APM路径不再位于所报告的前三条慢角setup路径。LRU压缩组合则由D-cache响应到mem_next_pc限制，说明布局会改变瓶颈；不将不同构建的最大裕量、最少LUT和最好执行效率拼在一起。

普通版与LRU压缩的三项组合已独立通过，135 MHz种子1为8725 LUT、5124 FF、WNS +0.274 ns；它没有优于仅压缩LRU的8640 LUT/+0.361 ns，不能把优化效果简单相加。因此后续实际141.75 MHz频点试验优先采用只压缩LRU的分支前递候选，而不是强行堆叠所有修改。

四个候选各自的20项PDS输入、两种十轮固件对应的18项仿真输入均独立核验；八份UART分别与前一轮分支专用前递原版逐字节相同。外部RV32UI/M合计784次执行及32个拒绝控制通过，逐案固件、退休指令和周期均与原版相同。各候选还完成两预测器缓存CPU参考/内存差分、14组精确乘除法中断、UART SoC和故障SoC检查，共56组精确中断用例。资格文件为build/{branch-bypass-lru,mul-csa,mul-csa_select16,branch-lru-csa}-qualification.json。

原生网表确认两种压缩LRU组合均为2个RAM256X1SP加1个RAM64X1SP、零LRU触发器；未压缩缓存的两种乘法候选仍为576个LRU触发器。四候选都使用4个APM，并未把乘法资源隐去。这里只在资源优化实验中检查映射，没有例行检查或上传Git状态。
