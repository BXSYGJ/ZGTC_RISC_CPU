# 有效地址进位选择的8/12位分割实验

日期：2026-09-07。本轮针对同步可写数据缓存DB55候选的135 MHz关键路径，隔离测试8/24和12/20两种有效地址加法分割。只改变rv32_core.sv中的有效地址组合表达式；缓存、H1预测器、ALU、PLL、全部接口和流水级数不变。两种候选均未通过本次135 MHz时序，不替代合格同步缓存候选，不改生产输入，不上传GitHub。

## 结构与边界

低位计算含进位的N+1位和；高位并行预计算进位0/1的两种结果，再用低位进位选择高位并拼接。高位结果使用既有syn_keep形式。N分别为8和12，区别于历史16/16方案；不能把旧方案在不同RAM/ALU背景下的结果直接移用。

scripts/test_address_partition.py先校验固定C4F0基线，再将候选地址块逆替换为原表达式，确认其余整个核心文本完全相同。组合测试覆盖原有20320组、分割边界64组及10000组全32位随机输入，共30384组/运行；每种分割分别运行候选和固定基线，共4次正例、121536次检查。检查完整有效地址、各访问宽度的对齐与JALR清位目标。

两种分割分别编译并运行5个错误注入：丢失进位、错误进位位、错误高位加1、错误低位清零、丢失立即数高位，共10个功能断言拒绝。组合强制输入测试不单独证明流水线、ISA或实板正确。严格板级lint已分别通过；完整CPU/ISA回归单独归档。

## 同源短测

隔离工程位于build/address-partition-8-stage及build/address-partition-12-stage。各自10轮性能与验证编译仿真均通过；性能3251073周期、2748941退休指令，验证3258866周期、2749614退休指令。

build/address-partition-physical-audit.json独立重新解析原始UART，核验实际执行文件、固件、18份编译输入及参数，并与同步缓存DB55对应短测逐字节比较：只有核心源码改变，完整UART和执行拍数均不变。短测使用精确相同132 MHz固件，仅用于功能/拍数对照，不是135 MHz正式分数，也没有绑定为135 MHz硬件结果。

## 135 MHz实际实现

全部使用PG2L200H-6FBB676、布局种子7、相同6000轮性能固件与135 MHz时钟约束。源快照20项除核心外完全一致；原始报告、生成顶层参数、布局配置、固件与位流均重新核验。

原生综合网表独立检查两组高位结果的驱动：8/24各24位，12/20各20位，均逐位存在且没有缺失或重复。这不是高位预计算被简单删掉造成的失败；保留这种结构本身也不保证布局后时序更优。

## 关键路径

8/24最差路径从数据DRM输出QA0[8]经旁路、读取载荷、alu_b[0]、ALU结果选择到mem_result[7]；8级逻辑，逻辑3.214 ns，布线4.034 ns（55.657%）。alu_b[0]在此路径扇出85。不能仅凭原地址端点不再最差就宣称整体提速。

12/20最差路径从数据DRM输出QB0[11]经载荷转发、高位加法address_high_zero[19]、d_req_address[31]到数据缓存state_reg[7]；10级逻辑，逻辑3.247 ns，布线3.945 ns（54.853%）。高位预计算与布线仍形成关键路径。

两者的数据RAM时钟到输出仍为1.644 ns。以后应结合实际转发/ALU与请求控制路径评估结构或布局，不靠继续盲目切分进位链声称优化到物理极限。
