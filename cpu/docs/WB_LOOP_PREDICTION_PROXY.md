## 小容量循环表代理

scripts/loop_prediction_proxy.py在原H3局部历史代理上叠加小表：只跟踪向后条件分支，以完成的连续taken次数学习循环长度；多次一致后才覆盖方向，长度变化、计数溢出、表项冲突会取消置信。只有原BTB实际命中时才能用先前存储的目标，不借用当前解析结果制造预测命中。当前计数器8位，表项2/4/8/16，置信门1/2，共8个有界配置。

7项单测覆盖稳定循环、置信不足、长度变化、溢出、表项冲突、BTB不命中、非循环和非法配置。build/run_wb_byte_loop_proxy.py先重新审计实际轨迹，再带窗口外预热进行解析顺序重放。

原H3模型在窗口内的预测PC逐项吻合；整个轨迹中窗口外仍有4个预测差异，不能掩盖或据此声称全周期模型完全相同。此代理省略在途取指、停顿、错误路径与精确查询时刻，不是实际RTL加速结果。
