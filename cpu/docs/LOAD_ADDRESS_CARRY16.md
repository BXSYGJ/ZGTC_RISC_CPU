# 146.25 MHz加载/普通地址的16位并行加法

## 电路与边界

在build/fetch-address-select-146250-stage这一完整配对父工程上，只将effective_address的32位加法换为16位低段与两种高段预计算。低段产生进位；高段同时计算不带进位、带进位的和，最后由低段进位选择。输入仍由load_address_bypass在branch_operand_a与forwarded_a之间选择，不增加流水级、寄存器或加载停顿，也不删去未对齐检查和高地址区域判断。

规范源experiments/load_address_carry16/rv32_core.sv的SHA-256为40E18D6C5AE343C8E2AFB6BF0E40B37656890B7F55811D876EBD323EF3FFC352。隔离工程build/load-address-carry16-stage的20项物理输入中19项与父工程完全相同，仅核心改变；PLL仍为146.25 MHz。该实现对完整32位操作数和立即数定义，不仅依赖加载指令的12位立即数性质。
