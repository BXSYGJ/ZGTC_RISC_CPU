# 独立直接分支提前恢复：功能通过，148.5 MHz时序仍拒绝

## 范围与结构

该候选从已完整配对的148.5 MHz carry16版本派生，隔离工程为build/early-direct-redirect-stage，规范核心为experiments/early_direct_redirect/rv32_core.sv，核心SHA-256为F48EF3341133BBBFF7155A132472B8CF8766A23F9B246F30DD136935BC14C535。20项物理输入只有核心改变，其余19项保持父版本一致；生产RTL不替换，不自动提交或上传GitHub。

前一个全面EX提前恢复候选的真实148.5 MHz PDS以WNS -2.841 ns拒绝，见EARLY_BRANCH_REDIRECT.md。本候选不是重跑旧实现，而是结构性分离提前判断与返回加载数据：

- 只提前恢复条件分支和JAL；JALR继续使用原MEM恢复路径。
- 提前比较器只接EX寄存操作数、非加载MEM结果、WB写回值；不直接接mem_value、d_rsp_data或原branch_operand。
- 与当前MEM加载的目的寄存器有关的分支禁止提前恢复，即使本拍返回数据已有效，也交给原有正确的执行/MEM路径。
- 提前目标独立计算为ex_pc+immediate，避免通过包含JALR/加载旁路的effective_address选择链。
- EX仍必须能够推进且无异常，旧MEM异常/MRET/FENCE.I/恢复具有优先权。mem_early_redirect仅防止同一分支重复恢复，保留原始预测值、预测器训练与精确退休机制。

这证明了源级结构意图，不自动证明物理路径已经消失或目标频率已达标。PDS构建20260908-081825-45f57db2使用PG2L200H-6FBB676、148.5 MHz、种子1、RemoteLab UART 115200及父版本相同6000轮性能固件；已完成最终布线、时序报告和位流生成，随后被实际时序门槛拒绝，包装进程退出1，没有生成合格manifest。
