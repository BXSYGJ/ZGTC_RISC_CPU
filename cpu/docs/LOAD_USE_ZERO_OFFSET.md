2026-09-07。目标同时考察执行效率、实际频点和面积，而不是把短测少几拍直接称为新正式成绩。生产RTL与GitHub不变。

## 零偏移专用地址通路

在BEQ/BNE专用前递的基础上，新增zero_offset_load = is_load && immediate == 0。加载的地址就是基址本身，不需要先通过一般地址加法器。对此类指令，地址选择已有的加载结果前递操作数branch_operand_a，并跳过相邻加载依赖停顿；LB/LH/LW/LBU/LHU都适用，不限于某个程序、PC或指针数值。

普通ALU、非零偏移加载、存储及JALR仍使用forwarded_a + immediate和原通用停顿；关系比较分支也不改变。branch_operand_a这个历史名称此时表示供相等比较和零偏移地址共同使用的选择器，不意味着把MEM加载值接回所有ALU输入。mem_ready、mem_flush及异常优先级不变，无效响应只能改变组合候选值，不能提前发出年轻访存请求。

核心源experiments/load_use_zero_offset/rv32_core.sv的SHA-256为A3D94B6A0D06FD5DCBD78483F2E58735FFCE3D455049853D8F5812D3A8612E2E。144 MHz实验阶段为build/load-use-zero-offset-stage；相对相等分支144 MHz候选的20项物理输入只更换这个核心。
