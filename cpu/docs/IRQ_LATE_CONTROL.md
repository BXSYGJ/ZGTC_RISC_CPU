# 中断控制条件的晚选择

日期：2026年9月8日。目标仍是实际时序合格频率≥160 MHz、执行效率≥3.18 CoreMark/MHz、资源效率≥0.052 CoreMark/LUT；本候选尚未达标。

## 选择依据与回退

定时器八字节比较的162 MHz构建20260908-182013-c692581d最终为9203 LUT、5179 FF、WNS -0.670 ns，比前驱-0.343 ns更差，不采用。原始来源审计及10项方法690.377秒、39项物理证据拒绝通过；这些仅确认失败结果可靠。最差路径仍经过interrupt_pending及流水使能，9级逻辑，逻辑1.779 ns、布线4.380 ns。比较宽度缩短并没有带来整体时序收益。

本候选回到较好的分支条件前置工程build/late-branch-predicate-stage，而不是叠加失败的字节定时器。规范CPU源experiments/irq_late_control/rv32_core.sv，SHA256 35744B09CF419EBFDBD68A3F1A6756D8231546C25184EED31F701AB309E63712；隔离工程build/irq-late-control-stage。另外19份物理输入保持不变，定时器仍为8C46872D243E7AA61B379FED21D85893C45F5466B1E8CC04C8870D239AA83F75。

## 结构及等价边界

原中断信号经过串行化检查、EX发射、早期冲刷、EX就绪及ID发射，最终驱动EX操作数寄存器使能。现在独立计算有中断和无中断时的EX发射与ID发射条件，末端再选择；早期重定向先计算无中断结果，再由中断禁止。

当中断待处理时，原逻辑精确等价于EX有效且MEM/WB均无更老指令才能发射。该条件成立时MEM相关等待、冲刷和加载依赖自然不成立，公共异常又允许越过乘除等待；这不是无条件放行中断。ID侧保留MEM冲刷、前端屏障和空EX允许填入的规则。CSR/MRET、乘除有效、加载依赖、分支重定向在无中断分支中原样保留。

没有新增流水寄存器或中断延迟。旧ex_ready和early_exception仍可观察；现有18个控制输出在两种气泡配置下与原实际RTL逐项比较，并另外检查中断发射与ID推进契约。
