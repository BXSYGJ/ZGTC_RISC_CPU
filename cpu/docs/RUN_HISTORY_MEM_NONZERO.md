# 连续长度历史与MEM非零资格组合

## 当前瓶颈与最小改动

单独连续长度历史版在157.5 MHz下为9461 LUT、WNS -0.138 ns，前三条真实慢路径从mem_instruction[11]经N1800_5非零归约进入MEM前递、ALU及mem_result。N1800_5的实际INIT为FFFFFFFE，输入为mem_instruction[7]至[11]；这是本次实现报告和网表的直接证据。

新CPU experiments/run_history_mem_nonzero/rv32_core.sv，SHA256 8F03BA996C5CE58CBA3F8499796B240B6B903946435EEDA48444FD158782E6A2。以已冻结732509AD CPU为父版，增加一个mem_rd_nonzero冗余状态位：与mem_rd在同一EX→MEM边沿分别捕获ex_rd!=0和ex_rd，异步复位同时为0，停顿时同时保持。替换五处mem_rd!=0保护，不改等待周期、WB字节预计算或流水级。预测器仍为0FF63743同容量连续长度历史版，不叠加任何循环表。

这不是旧C071父版/162 MHz试验已通过的延续：旧MEM资格版时序失败。当前CPU、频率、预测器和最慢路径不同，必须重新验证完整组合；不得因理论上减少一级就宣称最终时序通过。
