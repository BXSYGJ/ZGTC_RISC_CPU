## 实际瓶颈定位

原始前三条路径：D-cache request_address[8]分别到D-cache状态寄存器两处CE，及core/mem_instruction[10]到core/mem_result[29]。首条路径经D-cache有效位选择网络N2_16/N2_64，经过N6这一所选way1有效位节点和加载字节选择，再沿有效地址进位链到第30位，经内存区域判断返回D-cache状态控制。

首条路径15级逻辑，逻辑2.819 ns、布线3.757 ns（57.132%）。关键路径上的所选有效位节点扇出51；不是只由低两位对齐或存储器读延迟决定，也不能仅看路径起点就称它完全属于Cache内部。

报告参考周期37.0370 ns，生成周期6.8900 ns、半周期3.4450 ns，与已记录的半周期量化观测一致。审计仍检查真实波形及PLL参数，没有放宽板级时钟约束或修改原始失败报告。位流SHA-256为13CD54DE45C64C35DBFEDB8DF03AB0070D5431E6ABE8EB085341EE7C2574210F，仅留作追溯，不烧录为合格版本。
