有符号反向比较使用非相等且非正向小于；零与正负整数的比较单独处理。没有新增流水寄存器、等待周期、分支惩罚或异常延迟，其余前端冲刷、预测、加载地址前递和总线握手代码保持不变。六组比较带有18个相等/小于/合并结果边界，已在当前实际综合网表中全部找到；这仍不是完整网表形式等价或时序通过结论。
