# 完整功能 I-cache 有效位结构实验

本实验保留 GPIO、UART、42 位 ILA 数据、33 位触发和 1024 深度，只改变只读 I-cache valid 阵列的存储结构；D-cache、标签容量、数据 BRAM、替换、flush、错误返回及外设接口均未删减。复位后 valid 阵列逐项清零，清零完成前通过 back-pressure 阻止 cache 请求。

## 已验证

- `cache_ro_tb`：3427 项检查通过。
- `cache_ro_overlap_tb`：3588 项检查通过。
- `run_cached_tests.ps1`：预测器关闭/开启的缓存与 SoC 回归均通过。
- 双短测周期和 CRC 与完整基线一致；短测只作为行为筛选，不是正式分数。
- 固定 157.5 MHz PDS：种子 2 为 6706 LUT、3262 FF、WNS -0.322 ns；种子 3 为 6715 LUT、3264 FF、WNS -0.279 ns；种子 4 为 6767 LUT、3263 FF、WNS -0.306 ns。
- 保守的“只去除并行复位、保留 valid 读路径”候选最终仍被 PDS 推断成同类实现，种子 2 仍为 6706 LUT、WNS -0.322 ns；没有形成独立可晋级结果。

## 结论

候选资源效率潜力很高，但 157.5 MHz 时序失败，不能作为完整版本，也未插入 ILA、未上板、未替换 9374 LUT 基线。失败关键路径落在 I-cache 请求地址到命中计数使能，不能通过继续盲扫同一结构解决。下一候选必须恢复原 valid 读时序，只压缩 valid 的复位/控制实现，并重新通过完整外设、双 CoreMark、42/33 ILA 和物理时序验收。
