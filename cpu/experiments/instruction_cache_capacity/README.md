# Instruction-cache capacity experiment

The i9/i10 configurations use unchanged H3/C2 predictor and synchronous writable D-cache RTL, with a 16/32 KiB instruction cache. Both complete functional regressions but fail the tested 135 MHz seed-1 implementation. They are not production configurations or new hardware scores.

See ../../docs/INSTRUCTION_CACHE_CAPACITY.md for the exact evidence, test-fixture memory correction and next measured timing-path experiment.
