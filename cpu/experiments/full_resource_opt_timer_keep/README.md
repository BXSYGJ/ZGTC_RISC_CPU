# 完整外设定时器综合属性实验

本实验从 DC90363D 完整版本出发，仅删除定时器增量和比较逻辑的四个 syn_keep 属性。GPIO、UART、FIFO、定时器、中断、性能计数快照的端口、MMIO 地址、状态位和逐拍行为不改；不从 UART-only 或 no-MMIO 分支晋级。

## 固定比较条件

- 基线为 build/hardware/regfile-fanout-minimal-20260909-box5/hardware-coremark-qualification.json：157.5 MHz、501.0657302224314 CoreMark、3.181369715697977 CoreMark/MHz、9374 总 LUT。
- 硬件继续使用 I-cache set bits 9、D-cache set bits 6、BTB index bits 8 和全部已接受的数据/取指重叠参数。
- 性能固件复用完全相同的 6000 次、p2700000 固件 HEX，SHA-256 为 0E5EAD297589F9689CE8D9D60163DD7DD87FD71FF7EC11731545DE9CD9E99ABF。不得把自检或短测成绩计入完整得分。
- ILA 仍保留完整 42 位数据、33 位 Basic 触发、1024 深度、cpu_clk 逐拍采样。对新 ADF 按名称确认全部通道，不复用跨综合运行的数字索引。
- 晋级必须证明主频和执行效率不降低，资源效率高于完整基线；不能通过删除 GPIO/UART/ILA 或从分母扣除其资源实现。

## 当前验证

- test_full_peripherals.py：完整外设 3811 项检查，包含 GPIO 输入/输出、屏蔽与挂起、UART 回环/错误/FIFO、MMIO 背压、定时器和性能快照；定时器逐拍对照 9088 拍、65 次复位、32 次溢出。四个功能破坏变体全部被拒绝。
- 另外逐字核对 RTL：去掉四个综合属性后与完整基线相同，不以“测试未发现错误”代替接口保留证明。
- 完整候选 stage 为 build/full-resource-opt-timer-keep-stage。
- 双短测已通过，V0/V1 分别 3151519/3156276 周期、2748941/2749614 退休；CRC、缓存统计、配置和固件均与对应完整基线一致。证据为 stage/build/short-qualification.json；短测不是完整分数。
- 完整插核物理实验已完成且被淘汰，见下表。不再为该失败候选消耗完整 6000 次仿真或上板时间；不替换接受版本，不宣称达到物理极限。

## 物理结论：淘汰

| 实现 | 总 LUT | FF | 157.5 MHz setup WNS | 结论 |
| --- | ---: | ---: | ---: | --- |
| 接受的完整基线，含 GPIO/UART/42 数据 ILA | 9374 | 4984 | +0.078 ns | 保持基线 |
| 候选普通 PDS，尚未插入 ILA | 8879 | 4276 | -0.311 ns | 时序失败，不计完整资源收益 |
| 候选完整 42 数据/33 触发/1024 深度 ILA | 9398 | 4998 | -0.923 ns | 比完整基线多 24 LUT 且时序失败，拒绝晋级 |

普通实现运行标识为 20260910-003406-3d9e1c1d；完整插核运行标识为 20260910-004850-c85f133f，结果及原始报告哈希保存在 stage/build/ila/20260910-004850-c85f133f/result-qualification.json。全部 42/33 命名映射已由原厂 Inserter 确认，但这不能覆盖物理时序失败。

资源诊断表明，普通综合中 I-cache 实例占 2673 LUT，完整 peripherals（含其子模块）占 719 LUT；这些是综合级分层数据，不是额外叠加到总数的资源。下一方向应转向 I-cache 有效位存储结构，而不是继续删减外设或盲扫本候选布局种子。任何初始化/刷新结构改变都必须验证 reset、flush、错误返回、背压和完整 CoreMark 周期，尚未视为已实现。

## 入口

在 PowerShell 7 中运行 run_screen.ps1 进行隔离外设测试、双短测和固定参数普通 PDS；已有运行必须检查进程与产物，不能直接重跑。

run_ila.ps1 -SourceRun <运行标识> 使用同一完整物理源和固件重新映射、插入 ILA。audit_ila.py 校验真实名称、源哈希、顶层参数、约束、原始时序与总资源，始终把本地物理候选和完整实板计分分开。
