## 6. 遗留问题与阻塞点（JTAG 排查记录）

### 现象
- `cfg_scan_chain` 报 **"No devices detected while scanning the JTAG chain"**；
- JTAG 扫描 TDO 恒为全 `0xffffffff`（FPGA 无应答）；
- 期望 idcode：`0x50602899`（PG2L100H）。

### 已排除项
| 项 | 结论 |
| --- | --- |
| FTDI 驱动 | ✅ 正常（DriverStore 中 ftdibus/ftdiport，D2XX 可枚举） |
| USB 枚举 | ✅ 正常（PnP 三个 VID_0403 设备，COM3/COM4 存在） |
| 下载器频率设置 | ✅ 正常（1MHz/2MHz/10MHz 均可设置） |
| 位流编译 | ✅ 正常（blink_top.sbit 时序 Slack 34.379ns MET） |

### 剩余疑点（需现场核实，按优先级）
1. **J12 排线方向/位置**：10 针排线 1 脚红线对齐 J12 丝印 1 脚（不是插到 USB-C 串口）；通电时禁止插拔 JTAG；
2. **核心板与底板压合**：核心板板对板连接器（LB3524-G120）必须压合到位，否则 JTAG 信号到不了 FPGA；
3. **电源开关 SW1**：底板 SW1（DC12V 电源座 J14 旁）必须拨到 ON，核心板指示灯应亮；供电顺序建议「先接 JTAG 和电源线，再开 SW1」；
4. 若上述均无误仍不通：检查 core 板正面左上角 JTAG 触点（可作为无底板调试备选），或尝试 100 KHz 最低频率扫描。

### 建议接手人动作
- 现场按上述 1→2→3→4 顺序核实后，再执行第 7 节「T6 下载验证」的命令；
- 若确认硬件完好仍扫不到，可换一根排线/换 USB 口排除电缆故障。
